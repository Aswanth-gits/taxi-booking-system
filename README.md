TaxiGo - Taxi Booking System

TaxiGo is a simulation-based taxi booking system that efficiently assigns the nearest available taxi to customers and calculates fares based on distance.

### Features

- 📍 Nearest Taxi Allocation Logic
- ⏱️ Booking Time Management
- 💰 Automatic Fare Calculation
- 📊 Tracks Taxi Earnings
- 📋 Booking History Management
- ⚡ Optimized allocation for multiple taxis

### Core Logic

- Taxis are assigned based on:
  - Minimum distance to pickup point
  - Availability (free time)
  - Maximum earnings optimization

- Fare Calculation:
  - Based on distance between pickup & drop
  - Uses character-based distance logic (A → B → C...)
